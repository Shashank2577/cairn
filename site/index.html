Five layers, one stack

A cairn is a stack of stones that tells the next traveller where the path goes.

Cairn stacks five kinds of knowledge about your repository. Each answers one question an agent should ask before it touches code. Pick a stone.

A graph of files, symbols, calls and imports from Tree-sitter ASTs (25 grammars built in), plus docs, schemas and rationale comments. It is how Cairn knows the caller three hops away.

cairn trace path · cairn hubs · cairn areas

A spec-driven workflow of constitution, spec, plan and tasks, traced to the files that implement them. Drift checks find closed tasks whose code moved on.

cairn specs · cairn drift

Git history read for meaning: fixes, reverts, files that change together. With a model, facts with validity windows, like "true from March until the May refactor".

cairn timeline · cairn why <file>

Conventions, decisions, gotchas and preferences from people, agents and the repository itself. New memories update, merge with or retire the ones they overlap.

cairn remember "…" --kind convention · cairn recall

Prompts, files read and changed, and commands from every captured agent session, turned into observations and summaries the next session starts with.

cairn sessions search <query>

Questions

Before you install.

Anything else is in the onboarding guide.

Does my code get sent anywhere?

Not without a model. The map, impact, why, drift and seeded memory are computed locally. If Cairn finds a model, it calls the provider you configured, or your signed-in Claude Code CLI, and records every call in the ledger.

Which agents does it work with?

Claude Code, Codex, Gemini CLI, Cursor, OpenCode and GitHub Copilot get the MCP server and a session-start brief. Claude Code also gets session capture hooks, a status line, slash commands and sub-agents. Other agents can turn on capture with cairn sessions integrate install <agent>.

Do I need an API key?

No. The core is deterministic. A model adds summaries, timeline facts with validity windows, narrated answers and semantic drift checks, and Cairn can use your Claude Code plan for those with no key.

What does the model work cost?

Each sync's timeline work is capped at 150,000 tokens by default. Change it with [deep] budget_tokens, or turn it off. Small jobs go to the fast tier; only synthesis uses the deep one. Since 0.3, session notes cost 93–96% less per tool event, and Overview shows your spend from the ledger.

Will it slow down my commits?

No. Git hooks queue a background re-sync and return straight away.

How do I remove it?

Run cairn uninstall. It removes the hooks, agent wiring and files that setup added.
